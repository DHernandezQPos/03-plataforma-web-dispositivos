# One-Pager Comercial - Proyecto 3
## Plataforma Web de Registro y Configuracion de Dispositivos

## Propuesta de valor
Implementar una plataforma web de gobierno para administrar el ciclo de vida de terminales POS: alta, asignacion, configuracion y control por ambientes, con trazabilidad total.

## Problema de negocio que resolvemos
- Gestion manual y dispersa de terminales.
- Errores de configuracion en ambientes sensibles.
- Falta de control de permisos por rol y entorno.
- Dificultad para auditar cambios operativos.

## Solucion propuesta
Una plataforma central de operacion que:
- Registra y asigna dispositivos de forma controlada.
- Gestiona configuraciones por ambiente y por equipo.
- Aplica permisos robustos por perfil.
- Mantiene auditoria de cada cambio relevante.

## Beneficios para el cliente
- Menor error humano en operaciones criticas.
- Mayor velocidad para altas, cambios y soporte.
- Mejor cumplimiento y gobernanza.
- Visibilidad ejecutiva del parque de dispositivos.

## Alcance ejecutivo
- ABM de dispositivos y asignaciones.
- Configuracion por ambiente con reglas de control.
- Dashboard de estado operativo.
- Auditoria y reportes.
- Segregacion entre demo, qa y productivo.

## Criterios de exito
- Alta y configuracion sin inconsistencias.
- Permisos correctamente aplicados por rol/ambiente.
- Cambios sensibles completamente auditados.
- Rendimiento operativo adecuado para volumen de dispositivos.

## Entregables
- Plataforma web lista para operacion.
- API de gestion de dispositivos.
- Matriz de roles y permisos.
- Evidencia de pruebas funcionales, seguridad y rendimiento.

## Modelo de trabajo
Entrega por hitos verificables, con validaciones de calidad, seguridad y operacion en cada etapa, apoyado por IA/agentes.
